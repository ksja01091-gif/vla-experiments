# UR5e / OpenVLA 짧은 반복 실험

이 실험은 **기본 `openvla/openvla-7b`**가 찍힌 사진과 “주황색 블록을 집어라”라는 같은 지시를 보고 행동을 예측한 뒤, UR5e 시뮬레이터를 움직이고 **새 사진으로 다시 예측하는 연결**을 확인했다. 학습 실험이나 성공률 측정은 아니다.

## 먼저 확인한 조작

- MuJoCo에서 팔 끝에 작은 +x/-x, +y/-y, +z/-z 목표를 주자 각 축이 예상한 방향으로 움직였다. `verify_ur5e_controls.py --seed 7` 결과.
- 작은 +회전/-회전 명령도 x/y/z 세 축에서 각각 예상한 방향으로 측정됐다. 요청 5도에 대해 실제 각 축 변화는 약 4.26~4.30도였다. `verify_ur5e_rotation.py`와 `ur5e_rotation_check.json` 결과. 이 확인은 **UR5e 제어 코드의 방향**에 관한 것이며 OpenVLA 출력이 그 축을 뜻한다는 증명은 아니다.
- 이 시뮬레이터의 **Robotiq actuator 값**은 `0`일 때 열림(패드 중심 사이 약 93.14 mm), `255`일 때 닫힘(약 8.4 mm)이었다. 이것은 **OpenVLA 일곱 번째 출력의 뜻을 확인한 결과가 아니다.**
- OpenVLA 출력의 앞 여섯 값에 `1.0 -> 위치 0.01 m / 방향 5도`라는 임시 비율을 적용했다. UR5e 시범 데이터로 보정한 값이 아니므로 해석은 잠정적이다.
- 일곱 번째 출력 토큰은 5회 모두 OpenVLA 행동 토큰 범위 밖이었다. 잘라서 얻은 숫자는 집게의 예측값으로 인정하지 않았다. 따라서 이 실험에서 그리퍼 actuator는 안전하게 `0`에 고정했다.

## 실행 흐름

`step_00.png` → OpenVLA 예측 → UR5e/MuJoCo 물리 연산 500 tick(1초) → `step_01.png` → 다시 OpenVLA 예측 → … → `step_05.png`.

**모델 예측 5번**, 매번 물리 tick 500개였다. 500개의 tick은 모델 예측 500번이 아니다. 지시는 매번 같고, 입력 사진은 매번 바뀐다.

| 모델 예측 번호 | 입력 사진 | 팔 끝~블록 중심 거리 (m) | 블록을 5 cm 이상 들었나 | 그리퍼 |
| ---: | --- | ---: | --- | --- |
| 시작 | `step_00.png` | 0.8141 | 아니오 | 열림 |
| 1 | `step_00.png` | 0.8068 | 아니오 | 열림 |
| 2 | `step_01.png` | 0.8005 | 아니오 | 열림 |
| 3 | `step_02.png` | 0.7959 | 아니오 | 열림 |
| 4 | `step_03.png` | 0.7887 | 아니오 | 열림 |
| 5 | `step_04.png` | 0.7793 | 아니오 | 열림 |

거리 측정은 시뮬레이터의 `pinch` site와 블록 중심의 3차원 유클리드 거리다. 거리가 약 3.5 cm 줄었지만 최종 77.9 cm로 멀다. 블록 높이는 0.05 m 부근에서 그대로였고 집기·들기는 일어나지 않았다. `step_00.png`와 `step_05.png`에서도 블록이 바닥에 놓여 있다.

## 파일

- `verify_ur5e_controls.py`: 팔의 방향과 Robotiq actuator 개폐를 따로 확인.
- `verify_ur5e_rotation.py`, `ur5e_rotation_check.json`: 팔 끝의 회전축 방향을 별도로 확인.
- `ur5e_colab_sim_worker.py`: 모델 프로세스와 분리해 MuJoCo 장면을 만들고 행동을 1초간 적용한 뒤 사진·상태를 저장.
- `ur5e_openvla_closed_loop.py`: 모델 예측 → worker 실행 → 새 사진 재입력의 전체 반복. Colab에서 실행한 코드와 같은 경로를 독립 파일로 옮긴 것. **이 독립 파일 자체는 문법 확인만 했고 전체 재실행은 하지 않았다.**
- `closed_loop_20261119/prediction_step_*.json`: 각 입력 사진, 지시, 행동 토큰, 숫자, 토큰 유효성.
- `closed_loop_20261119/state_*.json`: 적용 후 팔·블록 위치, 거리, 블록 들림 여부, 물리 tick 수.
- `closed_loop_20261119/step_*.png`: 매 행동 전후의 카메라 사진.
- `closed_loop_20261119/closed_loop_summary.json`: 전체 5회 기록.

## 주의할 점

1. `0 = 열림, 255 = 닫힘`은 **시뮬레이터 actuator** 기준이다. OpenVLA 출력 번호와 직접 대응한다는 근거가 없다.
2. 모델은 UR5e + 주황색 블록에 맞춰 학습하거나 행동 범위를 보정하지 않았다. 이 실험은 연결 진단이다.
3. Colab에서 모델과 MuJoCo를 같은 Python 프로세스에 둘 때 런타임이 내려갔다. 별도 subprocess로는 장면 렌더링과 5번 실행이 완료됐다. 충돌 원인은 아직 확인되지 않았다.
