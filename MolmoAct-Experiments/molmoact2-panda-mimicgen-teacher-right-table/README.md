# MolmoAct2 Panda MimicGen 교사 모델의 네 물체 오른쪽 테이블 평가

MimicGen Pick Place D0 시범 400판으로 67,389스텝 학습한 Panda LoRA 교사 모델을 사용했습니다. 원래 환경의 오른쪽 칸막이를 평평한 테이블로 바꾸고, 우유·빵·시리얼·캔을 순서 상관없이 모두 옮기도록 평가했습니다. 기존 체크포인트의 LoRA rank는 32, 학습 시드는 777입니다.
