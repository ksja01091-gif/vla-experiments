세 모델 비교 + SP 선택 기준 실험 결과

조건: OpenVLA-7B, 같은 LIBERO 그릇 옮기 1개 작업, 5 epoch, batch4, LR0.0001, 기본 BF16 / 학습 값 FP32.
공개 시범에서 선택·전처리한 학습 전체 시범 40개(4025장면) / 검증 전체 시범 5개(462장면).
기존 LoRA8 학습 결과를 재사용. LoRA128과 SP128은 같은 사전학습 모델에서 새로 5번 학습.

0.9 | 61.98 | 4/5 | 14.71 GiB

0.7 | 41.89 | 4/5 | 14.71 GiB

유효 rank는 선택해 쓰는 방향 수. 기본 파라미터 수나 저장 파일 크기와 다르다.
이 구현은 전체 방향을 보관하고 dense 행렬 계산을 한다. 활성 rank 감소만으로 메모리/시간 절약을 뜻하지 않는다.
선택 기준 실험은 같은 SP 체크포인트에서 추론만 바꾼 것이다. 각 eta로 다시 학습한 실험은 아니다.
학습 속도는 단독 128장면 측정, 행동 속도는 학습/다른 평가 없이 같은 32장면에서 측정.
메모리는 PyTorch peak allocated, GPU 전체 사용량과 다르다.
같은 초기 상태 5개, 최대 220번 행동으로 평가. 새로운 상태의 성능을 보장하지 않는다.

논문의 핵심 규칙을 OpenVLA에 적용한 실험. pi0/SmolVLA/PiPER 전체 재현은 아님.
구체적 router 크기/활성함수/초기화/정밀도는 experiment_config.json에 기록.
표의 검증 loss는 모두 task CE. SP 보조 loss를 더한 total과 일반 LoRA CE를 섞어 비교하지 않음.
